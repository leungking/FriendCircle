# Random avatar pool

Profile header avatar pool, 8 images, 400x400 JPG, randomly picked on each
full page load when no custom avatar is set in theme settings
(`fcAvatarImage` empty or the theme default `assets/img/avatar.svg`).
A custom avatar URL or email in settings always overrides the pool.

Images are from Wikimedia Commons, cropped to square and resized to 400px.
See each file page for its license; images are replaceable, file names
`avatar-01.jpg` to `avatar-08.jpg` are neutral on purpose, so the theme
code does not hardcode city names.
