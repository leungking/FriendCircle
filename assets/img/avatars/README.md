# Random avatar pool

Profile header avatar and post-card author avatar pool, 35 images,
400x400 JPG, randomly picked on each page load when no custom avatar is
set in theme settings (`fcAvatarImage` empty or the theme default
`assets/img/avatar.svg`). A custom avatar setting keeps the original
behaviour: profile uses the setting, post cards use the author email
avatar. Commenter avatars are always email-based and are not in this pool.

Each post card draws independently, so cards on the same page can show
different pool images, and all change again on refresh. True random:
repeat on consecutive refreshes has probability 1/35, which is normal.

Images are from Wikimedia Commons, cropped to square and resized to
400px. See each file page for its license; images are replaceable,
file names `avatar-01.jpg` to `avatar-35.jpg` are neutral on purpose,
so theme code does not hardcode city names.

34 of the 35 cover the 34 provincial-level divisions (one capital /
municipality / SAR each); avatar-08 Suzhou is an extra, not a capital.
